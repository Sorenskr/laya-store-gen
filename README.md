# Laya 商店截图与视频生成器（1920×1080 横屏工作台）

专为 **Laya 语音社交应用** 打造的纯静态、零构建、所见即所得（WYSIWYG）商店推广海报与动态短视频生成工具。支持在浏览器中一站式编辑 Google Play 搜索卡片、应用导航指引、目标用户资料胶囊卡与双列短视频卡片流，并直接导出 **1920×1080** 高清 PNG 截图（含真透明背景 PNG）或带原声混音的 MP4 视频。

- 🌐 **在线访问地址**：https://sorenskr.github.io/laya-store-gen/
- 📦 **GitHub 仓库**：https://github.com/Sorenskr/laya-store-gen

---

## ✨ 核心功能亮点

1. **1920×1080 横屏双栏精致排版**
   - **左栏**：步骤 1 引导标题 + Google Play 商店下载卡片（支持可选手机状态栏） + 步骤 2 引导标题 + Laya 顶部内容标签与底部导航栏（带呼吸波纹动态指引箭头）。
   - **右栏**：步骤 3 引导标题 + 搜索框与多维个人信息胶囊卡 + 双列短视频/图文卡片流。

2. **画布内容简繁一键切换（编辑栏始终保持简体中文）**
   - 点击顶部工具栏或右侧面板的 **「画布：简体 ⇄ 繁体」**，即可一键将画布内所有展示文字在简体中文与繁体中文之间实时互转；右侧控制面板与顶部操作栏严格保持 **100% 简体中文**。

3. **全量本地自动保存（刷新/重开不丢失）**
   - 基于 `LocalStorage` + `IndexedDB` 双引擎自动持久化保存：所有修改的文案、手动拖拽位置、元素隐藏状态，以及**上传的本地 Logo、头像、海报横条、MP4 视频与自定义图片**均自动缓存在本地。
   - 刷新网页或关闭浏览器后再次打开，自动完整恢复上次编辑的画面与媒体文件；仅在手动点击右上角 **「↺ 重置默认」** 并确认后才会清空恢复初始状态。

4. **文字大小全局统一缩放 & 任意文字单独调大小**
   - **全部文字统一调整**：通过画布顶栏 `A−` / `A+` 或右侧总控区的 **「全部文字统一缩放比例（50% ~ 180%）」** 滑块，可一键等比例放大或缩小全画布所有文字，并支持一键复位。
   - **所有文字单独调整**：既可直接点击画布上的任意文字，在悬浮窗中单独拖动该文字的字号滑块（或点击底部选中栏的 `A−` / `A+`），也可在右侧面板展开 **「单独调整每一处文字大小」** 清单逐项精细调节，所有字号设置均自动保存在本地。

5. **画布直接点击改字 & 直接点击/拖拽上传**
   - **直点改字**：在左侧预览画布中直接点击任意标题、昵称、地区、标签、点赞数等文字，即可就地弹出毛玻璃悬浮输入框实时编辑。
   - **直点/拖拽上传**：直接点击画布上的应用主 Logo、商店小标、预览横条、奖杯/搜索图标、用户圆形头像或任意视频卡片（或直接将本地图片/MP4 拖入对应位置），即可一键替换媒体素材。

6. **三处核心搜索文字实时联动同步**
   - 右侧「同步总控框」、「步骤 3 标题」、「搜索输入框」与「个人卡片 ID」全链路双向绑定，输入任意数字、字母或中文词组，其余位置自动同步更新并高亮。

7. **丰富个人资料胶囊卡 & 视频作者头像昵称同步**
   - 个人卡片内置性别符号、年龄、等级徽章、声音个性标签、地区/城市位置、距离与在线绿点状态，并支持 **「🎲 一键随机生成个人资料」**。
   - 个人卡片的**圆形头像与用户昵称**自动实时同步至下方每一张视频卡片左下角，清晰体现作品归属。

8. **全页面元素自由移动、隐藏/删除与一键恢复**
   - 画布内全部 50+ 个独立元素与四大模块均支持鼠标自由拖拽排版（内置中心与边缘虚线吸附对齐参考线）。
   - 选中任意元素后点击红色 **「✕ 隐藏」** 胶囊钮、底部隐藏按钮或按下键盘 `Delete` / `Backspace` 键即可隐藏或删除；右侧「已隐藏元素恢复中心」与卡片元素开关条支持随时一键恢复。

9. **多种背景与真透明 PNG 模式**
   - 支持一键切换 **深色紫黑动态星云底**、**透明外背景（无黑底 32 位 RGBA 透明 PNG）**、**全透明无黑框（连卡片深色底板一并透明化）** 与 **浅色白底**，导出的透明 PNG 可直接拖入剪映、Premiere、Photoshop 等工具叠加使用。

10. **Gemini AI 文案生成 & 1080P PNG / MP4 导出**
   - 支持结合画面内容与主题词一键调用 Gemini 模型生成短视频标题、底部字幕与点赞数（同时内置离线爆款文案库兜底）。
   - 支持一键导出 `1920×1080` 无损 PNG 截图，或录制合成包含视频动态画面、微光粒子动画与 WebAudio 原声音轨的 `1920×1080` 高清 MP4 视频。

## 🚀 本地运行与静态部署

本项目采用 **原生 HTML5 + CSS3 + JavaScript** 构建，无任何构建打包依赖：

### 1. 本地直接运行
- **方式一**：直接双击打开根目录下的 `index.html` 即可使用全部功能（所有内置素材均已封装为无跨域限制的数据源）。
- **方式二**：使用任意静态文件服务启动（例如 VS Code `Live Server` 插件，或在项目根目录执行 `python -m http.server 8080` 后访问 `http://localhost:8080`）。

### 2. 部署至 GitHub Pages
1. 将本项目代码推送至 GitHub 仓库 `main` 分支根目录。
2. 进入仓库 **Settings → Pages**，在 **Build and deployment** 下选择 `Deploy from a branch`，分支选择 `main` / `/ (root)` 并保存。
3. 等待约 1 分钟即可通过 `https://<你的用户名>.github.io/laya-store-gen/` 在线访问。

## 🔑 可选：Google Apps Script 代理配置

若团队多人共享页面且不希望在前端暴露 Gemini API Key：
1. 打开 [script.google.com](https://script.google.com) 新建项目，将 `gas/Code.gs` 内容粘贴进去。
2. 在 **项目设置 → 脚本属性** 中添加属性 `GEMINI_API_KEY`。
3. 点击右上角 **部署 → 新建部署 → Web 应用**（执行身份选“我”，访问权限选“所有人”），复制生成的 `exec` 地址填入页面右侧「高级 API 设置」中的代理地址框即可。
